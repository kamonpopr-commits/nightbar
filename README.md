# NIGHTBAR — ระบบจัดการร้านบาร์

## วิธีเปิดใช้งานผ่าน Visual Studio Code บน Windows

### 1. ติดตั้งโปรแกรมก่อนใช้งาน

ติดตั้งโปรแกรม 2 รายการนี้:

- [Python](https://www.python.org/downloads/) เวอร์ชัน 3.11 ขึ้นไป — หากมีตัวเลือก **Add Python to PATH** ให้ทำเครื่องหมายก่อนติดตั้ง
- [Visual Studio Code](https://code.visualstudio.com/)

หากติดตั้งทั้งสองโปรแกรมแล้ว สามารถข้ามขั้นตอนนี้ได้

### 2. ดาวน์โหลดโปรเจกต์

1. บนหน้า GitHub นี้ กดปุ่มสีเขียว **Code**
2. เลือก **Download ZIP**
3. คลิกขวาที่ไฟล์ ZIP ที่ดาวน์โหลด แล้วเลือก **Extract All… → Extract**
4. จำตำแหน่งโฟลเดอร์ที่แตกไฟล์ไว้

> ต้องแตกไฟล์ ZIP ก่อน ไม่เปิดโปรแกรมจากภายใน ZIP โดยตรง

### 3. เปิดโฟลเดอร์ใน VS Code

1. เปิด **Visual Studio Code**
2. เลือกเมนู **File → Open Folder…**
3. เลือกโฟลเดอร์โปรเจกต์ที่มีไฟล์ **app.py** และ **START.bat** แล้วกด **Select Folder**
4. หากมีคำถามเรื่องความเชื่อถือของโฟลเดอร์ หลังตรวจว่าเป็นโปรเจกต์นี้ ให้เลือก **Yes, I trust the authors**

เมื่อเปิดถูกโฟลเดอร์ จะเห็นไฟล์ `app.py` และ `START.bat` ในแถบ Explorer ด้านซ้าย

### 4. สั่งเปิดเว็บ

1. เลือกเมนู **Terminal → New Terminal**
2. ในช่อง Terminal ด้านล่าง พิมพ์คำสั่งนี้ แล้วกด **Enter**:

   ```powershell
   .\START.bat
   ```

3. รอจนเห็นข้อความลักษณะนี้:

   ```text
   NIGHTBAR running at http://127.0.0.1:8765
   ```

4. โปรแกรมจะเปิดเว็บให้อัตโนมัติ หากไม่เปิด ให้เข้า:

   **http://127.0.0.1:8765/**

> ระหว่างใช้เว็บ ให้เปิด VS Code และ Terminal ที่รันโปรแกรมค้างไว้

### 5. สร้างบัญชีสำหรับทดสอบ

การเปิดครั้งแรก ให้เข้า:

**http://127.0.0.1:8765/setup**

ตั้งชื่อผู้ใช้และรหัสผ่านอย่างน้อย **10 ตัวอักษร** แล้วกดเริ่มใช้งาน จากนั้นใช้บัญชีนี้เข้าสู่ระบบที่:

**http://127.0.0.1:8765/login**

ระบบจะสร้างฐานข้อมูลให้อัตโนมัติ ไม่ต้องติดตั้ง DB Browser for SQLite เพื่อเปิดเว็บ และไม่มีบัญชีหรือรหัสผ่านเริ่มต้นให้ใช้ร่วมกัน

### 6. ทดลองใช้งาน

- **ผู้จัดการและพนักงาน:** เข้าสู่ระบบเพื่อจัดการโต๊ะ เมนู สต็อก ออเดอร์ การชำระเงิน และรายงาน
- **ลูกค้าดูเมนู:** http://127.0.0.1:8765/menu
- **ลูกค้าจองโต๊ะ:** http://127.0.0.1:8765/booking
- **ทดลองสั่งอาหาร:** เปิดโต๊ะจากฝั่งพนักงานก่อน แล้วเข้าลิงก์ทดลองสั่งของโต๊ะนั้นจากหน้าจัดการ QR

### 7. หยุดระบบและเปิดครั้งต่อไป

**หยุดระบบ:** คลิกใน Terminal แล้วกด **Ctrl + C** หากถาม `Terminate batch job (Y/N)?` ให้พิมพ์ `Y` แล้วกด Enter

**เปิดครั้งต่อไป:** เปิดโฟลเดอร์เดิมใน VS Code แล้วรัน:

```powershell
.\START.bat
```

ใช้บัญชีเดิมเข้าสู่ระบบได้ ข้อมูลที่บันทึกจะยังอยู่หากไม่ได้ลบโฟลเดอร์ `data`

### หากเปิดไม่ได้

| อาการ | วิธีแก้ |
|---|---|
| หา START.bat ไม่พบ | ตรวจว่าเปิดโฟลเดอร์ที่มี `app.py` และ `START.bat` อยู่จริง |
| แจ้งว่าไม่พบ Python | ติดตั้ง Python แล้วปิดและเปิด VS Code ใหม่ |
| เบราว์เซอร์ไม่เปิดอัตโนมัติ | เปิด http://127.0.0.1:8765/ ด้วยตนเอง |
| เข้าเว็บไม่ได้ | ตรวจว่า Terminal ยังแสดงว่าโปรแกรมทำงานอยู่ หากมีข้อผิดพลาด ให้อ่านข้อความใน Terminal |
